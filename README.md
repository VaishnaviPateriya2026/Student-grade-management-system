A simple **Python-based Student Grade Management System** designed to manage student details, marks, grades, and academic performance efficiently.

## Project Overview

The **Student Grade Management System** is a Python project that helps users store and manage student academic records. It allows users to enter student information and marks, calculate grades, and view the academic performance of students.

This project was developed as a **CSE academic project** to demonstrate the use of Python programming concepts such as functions, conditional statements, loops, data structures, and file handling.

## Features

* Add student records
* View student details
* Enter and manage marks
* Calculate total and average marks
* Automatically determine grades
* Search for student records
* Update student information
* Delete student records
* Store student data for future use
* Display student performance

## Technologies Used

* **Programming Language:** Python
* **Concepts:** Functions, Loops, Conditional Statements, Data Structures
* **Data Storage:** File handling / Local storage

## How It Works

1. The user selects an operation from the menu.
2. Student information and marks can be entered.
3. The system calculates the total and average marks.
4. A grade is assigned based on the student's performance.
5. Student records can be viewed, updated, searched, or deleted.
6. Data can be stored using file handling for later access.

## Grade Calculation

The grading system can be customized according to the project requirements. For example:

| Percentage | Grade |
| ---------- | ----- |
| 90–100     | A+    |
| 80–89      | A     |
| 70–79      | B     |
| 60–69      | C     |
| 50–59      | D     |
| Below 50   | F     |
